## Balloon Website

This repository contains a simple website for a balloon decoration business. The site is located in the `balloons-website` directory and consists of:

- `index.html` – main webpage with sections for about, services, and contact.
- `style.css` – styling for the layout and colors.
- `script.js` – small script for contact form interaction.

Open `index.html` in your browser to view the page.
